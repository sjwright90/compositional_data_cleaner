## Implement
- `python -m tests.fixtures.generate [--name project_basic] [--seed N]` writes `tests/fixtures/generated/<name>/` containing source files (xlsx/csv) and a `truth.json` listing which cases were injected and their expected counts.
- `project_basic` covers every §9 case: transposed wide sheet; long input with analyte/fraction/unit columns (Mn-D and Mn-T); `method` extra key (one pair merged, one split); spelling/whitespace variants; location aliases; unknown analytes; `D`/`T`/`N` incl. pH in `S.U.`; mixed/serial/ambiguous dates; decimal commas; qualifier variants incl. a code in two files; `detect_flag`/MDL/RL incl. blank-result non-detects; `>` values; QC samples; zeros in log and `allow_negative` analytes; duplicate types; sparse coverage incl. a location below `min_obs_per_cell` and an all-ND feature; high-DL; Eh; NO₃ as N and as NO₃; a ppm-in-water case; poor ion balance; dissolved > total.
- Deterministic: fixed seed, sorted iteration; identical bytes (or identical parsed content) on re-run.

## Done when
- Running the generator twice yields identical content and `truth.json`.
- A test asserts each §9 case listed above is present in `truth.json`.
- `tests/fixtures/generated/` is gitignored and not committed.
- `./scripts/check.ps1` passes.
