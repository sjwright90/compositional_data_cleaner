## Implement
- **Stage `parse`** (depends on `contract`; adds itself to `STAGES` and `tests/arch_inputs.py` with an `arch_vocab`-compatible builder built from a small `ContractResult`). Reads `ContractResult.cells` and `columns`; no file access.
- **Cell parsing** (rules from config tokens and `flag_map`, never constants):
  - leading `<` → ND, `censor = "<"`, DL = the number in the cell (`dl_type = parsed`); `<0` and `<0.0` give DL 0 with no special item (A12);
  - leading `>` → `censor = ">"`;
  - trailing letter codes (`0.5 J`, `0.5J`) → qualifier codes, combined with a mapped qualifier column;
  - whole-cell no-result tokens → no result; `ND` with a DL column present is a non-detect;
  - a blank cell stays missing and is never made an ND by a wide DL; a blank result with `detect_flag` = non-detect and a mapped DL column becomes an ND at that DL;
  - precedence: `detect_flag` column → leading `<` → qualifier (resolved in Clean);
  - decimal/thousands separators from the contract locale; scientific notation always accepted.
- **Reshape:** wide (including transposed) melted to `RawLong` columns per `RAW_LONG`; long input passes through with roles applied; `source_file`, `source_sheet`, `source_row` kept; `ingest_group_id` from the validated `IngestGroupKey` factory over the contract's key columns (analyte + fraction + unit by default; extra key columns allowed).
- **Drops and failures:** rows dropped for empty results counted and available as evidence (downloadable); unparseable cells listed with file, sheet, row, column and text.
- **Id construction (follow-up closed here):**
  - add a validating factory for `IngestGroupKey` in `core/ids.py` (non-empty key columns, no duplicates after normalisation) and use it in this stage;
  - add an AST architecture test over `core/**` asserting that the id classes (`FeatureId`, `IngestGroupKey`, `SampleKey`, `LocationId`, `DupGroupId`) are constructed only inside `core/ids.py`, with a detector self-test (planted offending source) like the existing `dash` import scan; classmethod factories defined in `core/ids.py` are the allowed route.
  - Later tasks add their own factories: `LocationId` in T13, `FeatureId` in T15, `SampleKey` in T23 or the first earlier task that constructs it.

## Done when

- A blank wide cell never becomes an ND; blank result with detect flag non-detect and DL column becomes ND at that DL.
- Rows in = rows out + counted drops for every fixture file (counts compared with `truth.json`); the transposed wide fixture and the standard wide fixture reach a valid `RawLong`.
- Unparseable cells are reported with their location and do not raise; two runs give identical frames.

- The id architecture test fails on a planted direct `FeatureId(...)` call in a temp `core/` module and passes on the tree; `IngestGroupKey` factory rejects empty/duplicate key columns.
