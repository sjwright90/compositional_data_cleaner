## Implement
- **Stage `harmonize`** (depends on `parse`; registered in `STAGES`; builder in `tests/arch_inputs.py` over a tiny `RawLong`, `arch_vocab`-compatible).
- **Canonical field × sheet matrix:** case-insensitive and edit-distance suggestions, every suggestion confirmed by the user; names for user-declared metadata columns; value maps for flagged categorical columns.
- **Location dictionary:** every distinct raw location (by `raw_location_key`) with row counts and sheets; normalised-equal strings grouped automatically; near matches (punctuation or zero-padding variants such as `MW-1`/`MW1`/`MW-01`) suggested, never auto-merged; an uploaded previous dictionary pre-fills, with conflicts shown and required to be resolved. `LocationId` values are built only through the validating factory added here.
- **Sample-type map:** raw values mapped to the canonical set, pre-filled from `tokens.json` `sample_type_aliases`.
- **Gates** (stored as recipe fields; per-sheet and per-value gates use indexed paths, matched by stable key): profile-required fields mapped in every sheet; every raw location mapped to a `location_id`; every raw sample type mapped when a sample-type column is mapped.
- **Data-dependent defaults:** the suggested maps (location groupings, sample-type map, field matrix) use the T11a `Stage.suggest` mechanism; `accept_defaults` stores the resolved maps and drift compares them with the current suggestion.
- Report items for every change, merge, drop or default with counts.

## Done when
- Row count out equals row count in for every fixture sheet (counted in the report).
- `MW-1` / `MW1` / `MW-01` in `project_basic` are listed as suggestions and stay separate until the user maps them; normalised-equal strings (case/whitespace variants) are grouped without a prompt.
- An unmapped location, an unmapped sample type and a sheet missing `location_id` each list as an unresolved gate field; `--accept-defaults` writes explicit entries.
- An uploaded dictionary with a conflicting row shows the conflict and does not apply silently.
- `LocationId` is built only via the factory (T12's architecture test passes); the factory rejects empty values.
- Stage `harmonize` is in `STAGES`; architecture tests pass with `arch_vocab`.
- `./scripts/check.ps1` passes.
