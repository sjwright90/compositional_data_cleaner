## Implement
- `Fraction` StrEnum (`D`/`T`/`N`).
- `FeatureId` frozen, ordered dataclass with `canonical()` (`analyte|fraction|unit|variant`) and `parse()`.
- `IngestGroupKey` with `from_raw()` and `id()` (short SHA-256 of canonical form).
- `normalise_token` (NFKC, trim, collapse whitespace, casefold, µ/μ → u).
- `SampleKey`, `LocationId`, `DupGroupId` value objects; qualifier-code normaliser `normalise_token(code).upper()`.
- Duplicate group ID: sample key + feature ID + SHA-256 of sorted candidate set `(value, cell_status, dl, codes)`.

## Done when
- Whitespace/case/µ variants produce the same ingest group ID.
- `FeatureId.parse(f.canonical()) == f` as a hypothesis property.
- Changing a display name or label has no input path to any ID (IDs are built only from normalised keys).
- Duplicate group ID is stable for reordered candidates and changes when a candidate value changes.
- `./scripts/check.ps1` passes.
