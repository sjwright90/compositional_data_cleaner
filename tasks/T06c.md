## Implement
1. **Log at commit.** Constructing `Project` writes nothing. Placeholder, drift and migration notices are held in memory (`Project.notices`), printed by the runner and written to the log only by `commit()`, as rows of that commit.
   - Placeholder notices go with every commit.
   - Drift notices are logged only with the commit of the stage that owns the gate.
   - Migration notices are logged at the first commit in a Project instance, then cleared in memory.
2. **Runner errors.**
   - `ValidationError` handler before `ValueError`: plain per-field lines naming the recipe file; exit 1.
   - Inside stage execution, re-raise `OSError` and the project's own plain-language errors to the friendly path. Any other exception prints `Internal error in stage <name>: <one line>; details in <project>/log/errors.log`, appends the traceback there (written by `Project`), exit 1.
   - Do not blanket-catch `KeyError`/`TypeError` into friendly text.
   - The audit log-read error names the file and line number. The cache-miss warning names the entry.
3. **Arch tests.** Session-scoped `Vocabulary` fixture from `tests/fixtures/config`. Result and mutation checks run over `STAGES` plus the stub stages (including `Gamma`). Replace the two weak tests with real contract checks, or delete with a decisions note. Add a test that nothing under `core/` imports `app`.
4. **Typed recipe helper.** `core/recipe.py::assemble_recipe` is the single construction path; `build_recipe` calls it, so the A15 outside-project rejection applies to both. `Project.current_recipe` uses it.
5. **commit() requires every dependency DONE.** A stale or missing dependency head raises `DependencyNotCommittedError` naming the stage, the dependency and its status ("commit <dep> first").
6. **Duplicate stage names** raise in `Project.__init__`.
7. **Test strength.** Real "not other" config-staleness test using an independent stub stage (`Gamma`); exit-code needles match the real help lines; `--recipe` test asserts the recipe is written where it points; `test_run_stage_without_commit` asserts the exact status.
8. **Derived counts.** `test_config.py` and `test_vocab.py` counts come from the fixture files.
9. **Fixtures.** Regenerate `tests/fixtures/generated/project_basic`; 41 cases including `lab_e_wide.xlsx`.
