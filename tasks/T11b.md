## Implement
- **New config fields (flagged per A16(b); minimal):**
  - `Tokens.header_separator: str` (default `_`) and `Tokens.fraction_codes: Mapping[str, Fraction]` (code → the existing `Fraction` from `core/ids.py`; codes matched after `normalise_token`);
  - `UnitRow.aliases: tuple[str, ...] = ()` (`;`-separated in `known_units.csv`, same form as analyte aliases), e.g. `mg/L` ← `mg_L`; `S.U.` ← `SU`;
  - `AnalyteRow.default_fraction: Fraction | None = None` (the existing type, no new `Literal`) and `AnalyteRow.dimensionless: bool = False`.
  - New CSV columns are optional in the loader so project layers without them still load. Collision validation covers unit aliases (an alias may not equal another unit or alias) and `check_new_unit` reports unit-alias clashes.
- **A16(e):** remove `units_row_labels` and `dl_row_labels` from `Tokens`, both `tokens.json` files, `AssumedConfig` in `tests/fixtures/truth.py`, and the assertions in `tests/test_fixture_generator.py` and `tests/test_config.py` that read them.
- **Seed values:** fixture config gets `default_fraction = N` and `dimensionless = true` for `ph`, unit aliases only for units the generator uses (`mg_L`, `ug_L`, `SU`), and no default fraction for `mn`/`fe`. `config/defaults/` gets the same columns with minimal starter values; its README says so.
- **A16(f) fixtures (header example and counts derived, not hard-coded):**
  - `lab_e_wide.xlsx` exactly the reference layout: one header row `Sample ID | Location | Date | Sample Type | Manganese_D_mg_L | Iron_D_mg_L | Iron_T_mg_L | pH_SU`, then data rows only, including `E0002 | MW-3 | 2023-08-07 | Normal | <0.005 | 0.309 | 0.914 | 7.06`;
  - cases inside it: fraction-less `pH_SU`, underscore unit aliases, a blank cell, `NM`, a `>` value (existing `wide_standard` case, re-described);
  - new file for negative case `wide_multirow_header_blocks`: the old form (header, units row, DL row with blank metadata cells, then data); `truth.json` records the 1-based sheet row number of the first non-data row;
  - at least one fixture header in `lab_c_wide_transposed.xlsx` or `lab_d_wide_decimal_comma.csv` deliberately uses a `header_rules` fallback form (e.g. `Manganese (Dissolved) mg/L`); `truth.json` records which file and header (`header_rules_fallback`);
  - update `REQUIRED_CASE_IDS` and the case list (41 → 42); rewrite `test_wide_standard_recount` for the single header line; add the new file to the file-enumeration test; regenerate `tests/fixtures/generated/project_basic`.

## Done when
- Config tests load the new fields from fixture config; an alias that equals another unit is blocked with a `ConfigError` naming both; `check_new_unit` reports a unit-alias clash; a project layer without the new columns still loads.
- `Tokens` has no `units_row_labels`/`dl_row_labels`; a `tokens.json` still holding them fails with the loader's unknown-field `ConfigError` naming the file.
- Reading generated `lab_e_wide.xlsx` raw (no header inference) equals the reference layout cell-for-cell for the header and the `E0002` row; the fraction-less `pH_SU`, `mg_L`, blank, `NM` and `>` cells are each present and counted from `truth.json`.
- `wide_multirow_header_blocks` is in `truth.json` and `REQUIRED_CASE_IDS`; case count is 42; two generator runs give identical content and truth.
- A test asserts every analyte header in `lab_e_wide.xlsx` (only that file) splits as `<analyte>[_<fraction>]_<unit>` against fixture config (analyte and unit resolve through `Vocabulary`); a second test asserts the `header_rules_fallback` header recorded in `truth.json` matches a `header_rules.csv` regex and has no valid A16 split.
- Existing tests pass; `./scripts/check.ps1` passes.
