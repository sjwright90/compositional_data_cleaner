## Implement
- `pyproject.toml`: `requires-python = ">=3.11"`, pinned dependencies from §4 (scikit-learn exact pin), `[test]` extra (pytest, hypothesis, dash[testing]), ruff/mypy config; no environment name anywhere.
- `core/pipeline.py` (contract types only): `ReportItem`, `StageResult`, `Stage` protocol with `name`, `version`, `depends_on`, `config_files`, `Params`, `run(inputs, params, vocab)`; a stage registry (`register_stage`, `registered_stages()`).
- `scripts/check.ps1`: runs `ruff check`, `ruff format --check`, `mypy core app tests`, `pytest -q`; stops on first failure and exits non-zero; uses the active interpreter via `python -m`.
- `tests/test_architecture.py`:
  - AST scan: no `import dash` / `from dash...` (or `dash_*`) in any file under `core/`.
  - For every registered `Stage`, `run` returns `StageResult` with a `report` tuple of `ReportItem` (parametrised over the registry; includes a detector self-test using in-test fake good/bad stages).
  - For every registered `Stage`, running does not mutate its inputs (compare a deep copy / frame hash before and after).
  - Layer helpers (e.g. impute layers) are not registered stages and are not subject to the `StageResult` check (A4).
