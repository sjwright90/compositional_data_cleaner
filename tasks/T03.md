## Implement
- `canonical_json(params)`: sorted keys, stable float/enum rendering.
- `file_sha256(path)` and `config_hash(stage, config_dir_layers)` over the files named in `Stage.config_files` (defaults plus project overrides, in layer order; missing optional file hashes as a fixed marker).
- `fingerprint(stage, params, dep_fingerprints, config_hash)` = SHA-256 of stage name, version, canonical params, dependency fingerprints, config hash (A7).
- `compute_staleness(stored: dict[str, str], recomputed: dict[str, str], depends_on) -> dict[str, Status]` (done/stale/blocked); staleness is computed, never set.

## Done when
- Changing a param, an upstream fingerprint or a config file a stage reads marks exactly that stage and its dependents stale.
- Changing a config file the stage does not read changes nothing.
- An unchanged rerun yields identical fingerprints.
- `./scripts/check.ps1` passes.

## Out of scope
Cache storage, `Project`, vocabulary loading, recipe, `Vocabulary.snapshot`.
