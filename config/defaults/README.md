# Starter configuration (placeholder)

This is a minimal starter set that stands in for the client's seed files. It is **not**
production vocabulary: replace the files with the client's configuration and delete the
empty `PLACEHOLDER` marker.

While `PLACEHOLDER` exists, the loader emits a warning ("using placeholder configuration"),
and the headless runner output, the status rail and the summary header repeat it.

Files are plain CSV/JSON. They contain no comments: `#` lines and `_comment` keys are not
skipped. Project files in `<project>/config/` are layered on top of these (additive; see
addendum A13).
